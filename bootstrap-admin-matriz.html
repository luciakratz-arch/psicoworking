Bootstrap — Admin Matriz

Ferramenta de uso único para ativar a conta Admin Matriz.

Use este arquivo uma única vez. Após o bootstrap ser concluído, o token é apagado automaticamente e esta ferramenta para de funcionar.
1

Clique em "Criar token e ativar" — isso cria o documento _bootstrap/token no Firestore com ativo: true.

2

Clique em "Abrir URL do Bootstrap" — a Cloud Function vai criar a conta contato@luciakratz.com.br com o papel admin_matriz e exibir um link para definir sua senha.

3

Clique no link exibido na página que abrir, defina sua senha e acesse psicoworking.web.app/psi/matriz/.

Se o documento já foi criado no Firestore Console, clique direto em "Abrir URL do Bootstrap".
